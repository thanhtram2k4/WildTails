Decision D12 mandates English for all repository text (documentation, prompts, CLAUDE.md, ADR templates, phase files).

**Why:** Consistent language across all 27 config/doc files reduces ambiguity for multi-agent workflows and meets thesis evaluation standards.

**How to apply:** When creating or editing any file in this repository, write all prose in English. Technical terms, code snippets, file paths and proper nouns (WildTails, Captain's Cabin, Space Dice, etc.) remain unchanged. Do not introduce Vietnamese text in new files.
