# Phase 09 – Security Hardening

## Goal

Audit all trust boundaries.

## Prompt

1. Threat model.
2. Auth/session review.
3. IDOR suite.
4. Role bypass suite.
5. File upload review.
6. Search/cache privacy review.
7. AI prompt-injection review.
8. Socket abuse review.
9. Rate limit.
10. Secure headers/CORS.
11. Secret scan.
12. Audit coverage.
13. Dependency review.
14. Run independent security reviewer.
15. Create remediation report.

## Human gate

Critical/high issues must be fixed or explicitly accepted in writing.
