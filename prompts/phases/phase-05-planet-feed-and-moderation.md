# Phase 05 – Planet Feed and Moderation

## Goal

Allow users to select content to share with the community.

## Prompt

1. Post, comment, reply, reaction, save.
2. Publish from journal via an explicit action.
3. Planet member policy.
4. Cursor pagination.
5. Rule-based feed score baseline.
6. Diversity rule.
7. Report flow.
8. Moderator scoped to correct planet.
9. Minimal block/mute if in P0.
10. Abuse tests.
11. UI loading/empty/error states.
12. Audit moderation.

## Stop condition

Do not automatically make a journal public when creating a post.
