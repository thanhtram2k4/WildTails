# Phase 02 – Architecture and Contracts

## Goal

Freeze boundaries before feature implementation.

## Prompt

1. Create NestJS module map.
2. Create API error envelope.
3. Create pagination contract.
4. Create auth principal contract.
5. Create visibility enum.
6. Create AI job state enum.
7. Create game state/event contracts.
8. Create point transaction contract.
9. Design Prisma schema draft.
10. Create ERD.
11. Create OpenAPI skeleton.
12. Create ADRs for auth, permission, AI adapter and game state.
13. Review privacy impact.
14. Do not implement full UI features.

## Human approval

Schema, permission model and public contracts must be approved before Phase 03.
