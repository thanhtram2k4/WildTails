# Phase 04 – Captain's Cabin and The Sun

## Goal

Complete the private journaling vertical slice.

## Prompt

1. Journal folder, entry, version, tag.
2. PRIVATE by default.
3. SELECTED_USERS sharing with expiry/revoke.
4. Goal and progress.
5. Link journal to goal.
6. Editor UI.
7. Folder/list/basic search.
8. Cross-account denial tests.
9. Immediate revoke test.
10. Audit share/permission change.
11. Signed media upload skeleton if in scope.
12. Browser evidence using two accounts.

## Critical gate

Does not pass if User B can read User A's private journal via API, search, cache or media.
